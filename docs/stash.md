# Stash 便签 功能设想

> 一句话：按一下快捷键就能记，记完不用管；以后翻出来，可以一键扩写成需求，交给 agent 实施。

## 核心原则
1. **记录零决策**：不选分类、不起标题、不选项目，打开就写，写完就走。
2. **整理延后**：分类、关联、扩写都在回看时做，或者交给 AI 在后台建议。
3. **数据是纯文件**：一条记录对应一个 `.md` 文件加一个资源目录。agent 可以直接读和 grep，也能同步和备份。

---

## 1. 记录（Capture）

**呼出**
- 全局快捷键（默认 `⌃⇧Space`，可以改）呼出一个浮动面板。
- macOS 上不进 Dock，也不抢当前 App 的激活状态；Windows 上不进任务栏。
- 面板常驻、预热好，按下就能打字。
- 再按一次快捷键，或者按 `Esc`，隐藏面板并自动保存。没有"保存"按钮。

**输入**
- 粘贴图片、拖入文件，直接嵌进正文。
- 粘贴网页内容时自动转成干净的 Markdown，粘贴链接时显示标题卡片。
- 呼出前有选中的文本，就自动作为引用块带进来。
- `⌘↩` 保存并关闭，`⌘N` 在面板里再开一条新的。
- 还可以选老的

**续写**
- 距离上一条不到几分钟时，默认续写那一条，面板顶部有一个"新建"开关。
- 适合一个想法分好几次补充的情况。

**自动记录上下文**（静默保存，不打扰记录）
- 当时的前台 App 和窗口标题；
- 浏览器当前 URL；
- 如果当时在 BaoCode 里：当前项目、分支、对话，作为默认的关联建议。

---

## 2. 编辑器

- 基于 Markdown 的所见即所得：写的时候是富文本，存下来是 md。
- 支持标题、列表、任务 `- [ ]`、代码块（带高亮）、表格、引用、图片缩放。
- 不要命令块，没有###这样的标题支持，这是特意的，支持cmd+b加粗 ，超链接，拖片粘贴进来可以拖动控制大小(4个点)和位置
- 支持公式，不支持表格，list 项 支持滑词的颜色背景色，可以ai快速优化(要快，最好带前面提到的上下文)
- 行内引用，都是可选的：
  - `#标签`
  - `@项目`：关联 BaoCode 项目
  - `[[另一条 Stash]]`：互相链接
- 目标是轻、快：空白面板到可输入的延迟感知不到。

---

## 3. 回看（Browse）

**卡片形式**
- 按时间分组：今天、昨天、过去 7 天、过去 30 天、更早。
- 每条显示：自动标题、摘要、首张图片的缩略图、关联项目的标记。
- 每条都有 #+数字的标号，类似 #1 #2 类似issue 

**状态**
| 状态 | 含义 |
无状态

**筛选与搜索**
- 只支持全文AI搜索，并对图片做 OCR，截图里的文字也能搜到。

**操作**
- 置顶、合并多条、把一条拆成多条、批量关联项目。

**AI 后台整理**（只给建议，不自动改）
- 给没有标题的记录生成标题；
- 建议关联的项目和标签，点一下确认；
- 发现几条在说同一件事时，提示合并。

## 4. 和 BaoCode 联动（核心）

**扩写为需求**
- 选一条或多条 Stash，点"扩写为需求"，BaoCode先把它维护为结构化需求
- 在关联项目里新开一个 agent 对话。对话框@那个便签+一段固定的开始文本(用worktree分支提交完成后必须清理分支和我worktree，当然要看用户是否用git，突出智能)
- 用户决定是否点击发送按钮

**双向链接**
- Stash 上显示"已在对话 X 中实施"，点击直接跳过去。
- 对话顶部显示"来源：Stash · xxx"，点击可以查看原始记录。
- 对话结束或任务完成后，Stash 状态自动变为"完成"。

**在对话里使用**
- 把一条 Stash 拖进聊天输入框，就把它作为附件带上。
- 在输入框里用 `@` 搜索并引用stash (放到文件下面)。

**从对话反向写入**
- 对话里说"这个先记下来，以后再做"，agent 就创建一条 Stash，自动关联当前项目和对话。
- 适合实施过程中冒出来、但不想打断当前任务的想法。

**项目 Backlog**
- 项目视图里有一个 Stash 面板，列出关联到这个项目的所有记录。

**GitHub 互通**（可选）
- 一条 Stash 一键转成 GitHub Issue，图片一起带上。
- 也可以从 Issue 反向导入成 Stash。

---

## 5. 存储 用Stash标号
```
~/BaoCode/Stash/
  1.md      # 正文 + frontmatter（状态、项目、标签、来源上下文）
  1/        # 图片、文件
```
- 纯文件，可以用任何编辑器打开，可以放进 git 或网盘。
- 索引（搜索、OCR 结果）单独缓存，删掉可以重建。

---

## 6. 跨端（后期）暂时不做
- 手机端从分享菜单把截图、链接、文字、语音转写直接存进来，通过 relay 同步到桌面。
- 手机只负责记录和浏览，扩写和实施在桌面做。
