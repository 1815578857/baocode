像素加载动画

一次小更新：智能体和子 Agent 换上了新的像素加载动画，样式和速度都可以自己选；Windows 和窄窗口下的设置界面也更整洁了。

新功能
- 像素加载动画：智能体工作中、子 Agent 运行中都显示 3×3 的像素动画，默认为“堆满再清空”，颜色略带主题主色。
- 设置 → 外观：可以分别为“智能体加载中”和“子代理运行中”选择加载样式（十多种可选，原来的圆环也在其中），并调节速度。

改进
- 对话回合结束后，如果还有后台任务（子 Agent、后台命令）在运行，侧栏、对话列表和 IDE 中会继续显示运行中，直到任务完成。
- 后台运行的子 Agent 与其他子 Agent 使用同样的加载动画；“转到后台”按钮换了新图标；输入框上方的后台命令不再转圈，改为显示终端图标。
- Windows 上打开设置时，顶栏不再显示对话的控制按钮和标题，改为放置设置页列表的展开/收起按钮。
- 窄窗口下设置页左右留白减小，给卡片留出更多空间。
