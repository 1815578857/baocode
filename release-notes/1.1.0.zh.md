对话缩略图与回合统计

这次更新给对话加了一张缩略图，长对话一眼看清全貌、点一下就能跳过去；每轮回复下方还会显示复制按钮和这一轮的用量。

新功能
- 对话缩略图：对话左侧显示整段对话的缩略图，你的消息、代码、表格、改动都能分辨出来。滚动时一块液态玻璃标出当前所在位置，玻璃下的内容会像 macOS 程序坞一样轻微放大；点击或拖动缩略图即可跳转。
- 缩略图显示时代替右侧滚动条，消息列左右也会让出一些空间；窗口太窄时自动隐藏，恢复滚动条。
- 设置 → 外观：可以关闭「对话缩略图」，关闭后和以前一样使用右侧滚动条。
- 回合底栏：每轮回复结束后，下方有「复制回复」按钮，并淡淡地显示这一轮的输出速度、用了多少 token、耗时和花费（拿得到的才显示），鼠标悬停可以看到明细。
