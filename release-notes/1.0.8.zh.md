精进不少

本次更新覆盖面很广：可以从站点一键导入上游，SSH 主机能在侧栏直接管理，资源管理器支持撤销和拖进拖出，第一次使用时会自动下载 Claude Code，还修复了一批长期存在的问题。

新功能
- 一键导入上游：在支持的站点上点导入按钮，确认后即可添加上游及你自己的密钥（只导入名称、协议、地址和密钥）。设置 → 模型 顶部列出官方收录的站点，你用过的站点排在最前；收录列表随官网实时更新，不必等新版本。
- 模型选择器显示各模型厂商的标识，每个上游的标题前也有图标。图标可以自己选（厂商标识、网站图标、emoji、内置图标或上传图片）；没设置时按地址识别厂商，或自动取站点的网站图标。
- 排队消息：智能体工作时发送的消息不再混在对话里，而是停在输入框上方，依次发送。每条都可以撤回编辑、中断当前任务立即发送，或者移出队列。
- 侧栏新增“打开项目”，并可以管理 SSH 主机：在本机和主机之间切换，添加、重命名、断开或移除主机。新对话的文件夹菜单也列出 SSH 主机和它们的项目，可以直接选择主机上的目录。
- Windows 上的 SSH 支持密码登录（需要 OpenSSH 8.4 或更新版本）。
- 资源管理器：新建、删除、移动文件都能撤销和重做（Cmd/Ctrl+Z）；可以从其他应用拖入文件，也可以把文件拖出窗口到其他应用（远程项目的文件会先下载）；远程项目的文件可以复制到系统剪贴板，本机文件也能粘贴上传进去；没有权限的文件夹会给出提示。
- 支持自动保存：在文件菜单中开启“自动保存”，或设置 files.autoSave（停止编辑一段时间后、切换编辑器时或离开窗口时保存），与 VS Code 一致。
- 技能页（原“自定义”）支持远程项目，可以直接管理远程主机上的技能、子 Agent、命令、规则和 MCP 服务器。新建时名称可以用中文。
- MCP 服务器会逐个检测能否连接：连不上时显示原因（退出码、超时、需要登录）和输出日志，可以单独或全部重新检测。
- 自动安装 Claude Code：本机没有 Claude Code 时，开始第一个对话就会自动下载并显示进度。默认使用本机已安装和 BaoCode 下载的版本中最新的一份；也可以在 设置 → 通用 中指定路径。
- 设置 → 更新 新增“诊断日志”：遇到问题时可以附上备注，把错误日志上传给开发者，上传后会得到一个报告编号。只有点上传才会发送，日志中的用户目录会替换成 ~。
- 设置页左侧的页面列表可以拖动调整宽度，也可以用 ⌘B 隐藏；窗口较窄时会变成抽屉。
- GPT 等会给出思考摘要的模型，其思考过程以摘要的标题显示，展开后可以看到内容。
- 变更审查中，改动过的图片显示为图片本身，不再显示为文本。
- 提问卡片可以收起和展开。

改进
- 每个模型会记住自己的思考强度和上下文长度。切换模型时不再先发一条测试请求。
- 设置了子 Agent 模型后，所有子 Agent 都会使用它（定义为 inherit 的除外）。此前子 Agent 可能仍在使用主模型。
- Windows 上的文字更清晰：字号对齐到像素，并改进了文字渲染，效果接近 Chrome。
- 检查更新改为启动 10 秒后进行一次，之后每 5 分钟检查一次，新版本能更快送达。
- 模型选择器：搜索框可以点击输入，列表上下边缘渐隐，悬停时更流畅，菜单配色与右键菜单一致。
- 悬浮提示不超过窗口宽度的 90%，与窗口边缘保持距离。

修复
- 停止任务后，还在运行中的工具、命令和子 Agent 不再一直转圈，而是显示为失败（Claude Code 和 Codex）。
- 长对话的滚动条比例正确，拖动时不再乱跳。智能体自己发起的回合（例如后台任务完成后的报告）不再把对话跳到底部，也不再折叠你正在看的内容。
- 其他工具运行 code --version 之类的命令时，不再弹出一个空白的 BaoCode 窗口。
- SSH 取消登录或密码错误后，不再反复弹出密码框；启动时恢复的远程项目也不会弹出好几次。
- 在 Windows 上打开 SSH 项目的变更文件列表时，不再出现灰色的错误框。
- macOS 上，智能体运行的命令可以向其他应用发送 Apple 事件（例如用 osascript 控制其他应用），此前会被系统直接拒绝。
