接入 BaoCode 一键导入

用户在你的令牌页点一下，就能把你的 API 添加到 BaoCode。只要导入一直可用，BaoCode 就在 设置 → 模型 中免费展示你的站点。

你能得到什么

在 BaoCode 的 设置 → 模型 中，和其他接入了一键导入的上游一起展示一张卡片，每次打开页面顺序随机。点击卡片打开你的站点，可以带推广参数。展示不收费，也不代表 BaoCode 为你担保。

new-api：加一行配置，不用改代码

在 系统设置 → 聊天设置 中加入下面这一项。new-api 会替换 {address} 和 {key}，令牌列表里的每个令牌都会多出 BaoCode 选项：

{ "BaoCode": "https://baocode.dev/import#v=1&name=你的站点&protocol=anthropic&url={address}&key={key}" }

如果用户应该走 OpenAI 接口，把协议换成 protocol=openai-chat 或 openai-responses。请用自己的令牌试一次：部分 new-api 版本替换出的 key 不带 sk-，这时写成 key=sk-{key}。

其他站点：放一个链接

在每个令牌旁放一个链接，在新标签页打开：

https://baocode.dev/import#v=1&name=…&protocol=…&url=…&key=…
参数含义
url必填Base URL，http 或 https；Anthropic 协议不带 /v1。
protocol可选anthropic（默认）、openai-chat 或 openai-responses。
name可选站点名称，即 BaoCode 中上游的名称。
key可选用户的完整 key。
v可选1。

每个参数值都要用 encodeURIComponent 编码。参数必须放在 # 后面，不能放在 ? 后面：浏览器不会把 # 后的内容发给任何服务器，key 只会从你的页面直接到用户的 BaoCode。baocode.dev 的页面读取后会把它从地址栏中清除并打开 BaoCode，BaoCode 会先向用户展示要添加的内容，经确认后才添加。

请不要在令牌页引用 baocode.dev 的任何脚本，一个普通链接就够了。

申请展示

导入可用后，提交 issue，写明站点名称、卡片链接、API 域名和一句话介绍。维护者会实际试一次导入、联系你要 Logo，并在下个版本中加上你的卡片。

导入失效或误导用户的站点会被下架。
