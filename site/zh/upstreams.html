接入 BaoCode 一键导入

用户在你的令牌页点一下，就能把你的 API 添加到 BaoCode。只要导入一直可用，BaoCode 就在 设置 → 模型 中免费展示你的站点。

交给 AI 来做

在你站点的代码仓库里，把下面这段发给 AI 编程助手（Claude Code、Codex、Cursor……）。它会判断站点用的是什么并完成接入；细节见后文。

请帮我在我的 API 站点上接入「导入到 BaoCode」一键导入。BaoCode 是一个桌面 AI 编程客户端，接入说明见 https://baocode.dev/zh/upstreams 。

1. 先看清这个站点是什么：
   - new-api / one-api 系（有「系统设置 → 聊天设置」）：不用改代码。告诉我在聊天设置里加这一项：
     { "BaoCode": "https://baocode.dev/import#v=1&name=<站点名>&protocol=anthropic&url={address}&key={key}" }
     并提醒我用自己的令牌试一次：如果导入后的 key 缺少 sk- 前缀，改成 key=sk-{key}。
   - 其他（sub2api 或自研）：在令牌 / API Key 列表里每个 key 旁边加一个「导入到 BaoCode」按钮，按第 2 条实现。

2. 按钮在新标签页打开（target="_blank" rel="noopener noreferrer"）：
   https://baocode.dev/import#v=1&name=<站点名>&protocol=<协议>&url=<API Base URL>&key=<完整 key>
   - name：站点名，用站点配置里的名称。
   - protocol：anthropic（站点提供 /v1/messages）、openai-chat（/v1/chat/completions）或 openai-responses（/v1/responses）。支持 anthropic 就用 anthropic；不同 key 走不同协议的（比如按分组区分），按这个 key 的实际情况选。
   - url：用户调用 API 的 Base URL，和站点上展示给用户的一致，http 或 https；anthropic 协议不带 /v1。
   - key：这个 key 的完整值，不是打码后的显示值；列表里只有打码值的话，在点击时再取完整值。
   - 每个值都用 encodeURIComponent 编码。
   - 参数必须放在 # 后面，绝不能放在 ? 后面：浏览器不会把 # 后面的内容发给任何服务器，key 不经过 baocode.dev 或任何服务器。

3. 按钮文字用「导入到 BaoCode」，样式和页面上现有的按钮保持一致。文字前放 BaoCode 标志：用 <img> 引用 baocode.dev 上的在线图片，不要把图片下载进项目，也不要自己画或内联 SVG。
   - 地址：https://baocode.dev/brand/baocode-mark-<颜色>-<高度>.webp
   - 颜色：black 用在浅色按钮上，white 用在深色或彩色（主色）按钮上；站点有深浅两种主题的，跟着主题切换。
   - 尺寸：标志宽高比 4:3。按按钮文字大小选显示尺寸，src 用 1x 那张，srcset 给高分屏加 2x、3x：
     · 文字 13–14px（小按钮、表格行里的按钮）：显示 16×12，高度 12 / 24 / 36
     · 文字 15–16px（普通按钮）：显示 24×18，高度 18 / 36 / 54
     · 文字 18px 以上（大按钮）：显示 32×24，高度 24 / 48 / 72
     例：<img src="https://baocode.dev/brand/baocode-mark-black-12.webp" srcset="https://baocode.dev/brand/baocode-mark-black-24.webp 2x, https://baocode.dev/brand/baocode-mark-black-36.webp 3x" width="16" height="12" alt="">
   - 标志和文字间隔 6px 左右，垂直居中。写上 width 和 height，加载前不会跳动；alt 留空，按钮文字已经说明了。
   - 地方够、想放方形应用图标时（比如导入说明、卡片里）：https://baocode.dev/brand/baocode-icon-<尺寸>.png，尺寸有 16、24、32、48、64、96、128、256、512。src 用显示尺寸那张，srcset 加 2 倍那张，例：<img src="https://baocode.dev/brand/baocode-icon-32.png" srcset="https://baocode.dev/brand/baocode-icon-64.png 2x" width="32" height="32" alt="">
   - 站点设了 CSP 的，把 https://baocode.dev 加进 img-src。
   除了这些图片，不要引用 baocode.dev 的脚本或样式，后端也不要请求 baocode.dev。

4. 做完后告诉我改了哪些文件，以及怎么验证：点按钮应打开 baocode.dev/import，页面上显示站点名、协议、地址和打码后的 key；装了 BaoCode 的话，会弹出导入确认。

你能得到什么

在 BaoCode 的 设置 → 模型 中，和其他接入了一键导入的上游一起展示一张卡片，每次打开页面顺序随机。点击卡片打开你的站点，可以带推广参数。展示不收费，也不代表 BaoCode 为你担保。

new-api：加一行配置，不用改代码

在 系统设置 → 聊天设置 中加入下面这一项。new-api 会替换 {address} 和 {key}，令牌列表里的每个令牌都会多出 BaoCode 选项：

{ "BaoCode": "https://baocode.dev/import#v=1&name=你的站点&protocol=anthropic&url={address}&key={key}" }

如果用户应该走 OpenAI 接口，把协议换成 protocol=openai-chat 或 openai-responses。请用自己的令牌试一次：部分 new-api 版本替换出的 key 不带 sk-，这时写成 key=sk-{key}。

其他站点：放一个链接

在每个令牌旁放一个链接，在新标签页打开：

https://baocode.dev/import#v=1&name=…&protocol=…&url=…&key=…
参数含义
url必填Base URL，http 或 https；Anthropic 协议不带 /v1。
protocol可选anthropic（默认）、openai-chat 或 openai-responses。
name可选站点名称，即 BaoCode 中上游的名称。
key可选用户的完整 key。
v可选1。

每个参数值都要用 encodeURIComponent 编码。参数必须放在 # 后面，不能放在 ? 后面：浏览器不会把 # 后的内容发给任何服务器，key 只会从你的页面直接到用户的 BaoCode。baocode.dev 的页面读取后会把它从地址栏中清除并打开 BaoCode，BaoCode 会先向用户展示要添加的内容，经确认后才添加。

请不要在令牌页引用 baocode.dev 的任何脚本，一个普通链接就够了；下面的图标可以引用。

申请展示

导入可用后，提交 issue，写明站点名称、卡片链接、API 域名和一句话介绍。维护者会实际试一次导入、联系你要 Logo，并在下个版本中加上你的卡片。

导入失效或误导用户的站点会被下架。
