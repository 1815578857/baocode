Add one-click import to BaoCode

Your users add your API to BaoCode with one click from their key page. BaoCode lists your site in Settings → Models for free, for as long as the import works.

Have your AI do it

Send this to your AI coding assistant (Claude Code, Codex, Cursor…) in your site’s repository. It works out what your site runs and does the rest; read on for the details.

Add one-click "Import to BaoCode" to my API site. BaoCode is a desktop AI coding app; how the import works: https://baocode.dev/upstreams

1. First find out what this site is:
   - new-api / one-api (it has System Settings → Chat Settings): no code needed. Tell me to add this entry in Chat Settings:
     { "BaoCode": "https://baocode.dev/import#v=1&name=<site name>&protocol=anthropic&url={address}&key={key}" }
     and to try it once with a key of my own: if the imported key lacks its sk- prefix, write key=sk-{key} instead.
   - Anything else (sub2api, or our own code): add an "Import to BaoCode" button next to each key in the key / token list, as in step 2.

2. The button opens, in a new tab (target="_blank" rel="noopener noreferrer"):
   https://baocode.dev/import#v=1&name=<site name>&protocol=<protocol>&url=<API base URL>&key=<the whole key>
   - name: the site's name, as the site's settings have it.
   - protocol: anthropic (the site serves /v1/messages), openai-chat (/v1/chat/completions) or openai-responses (/v1/responses). Use anthropic where the site supports it; where keys differ (by group, say), pick by this key's.
   - url: the base URL users call the API at, as the site shows it to them, http or https; without /v1 for anthropic.
   - key: the key's whole value, not the masked one shown; if the list only has the masked one, fetch the whole key when the button is clicked.
   - Encode each value with encodeURIComponent.
   - The parameters go after the #, never after a ?: browsers never send what follows a # to any server, so the key goes through neither baocode.dev nor any other server.

3. Label the button "Import to BaoCode" and style it as the page's other buttons. Put BaoCode's mark before the label: an <img> of the image online at baocode.dev, never a copy downloaded into the project, nor an SVG drawn or inlined.
   - Address: https://baocode.dev/brand/baocode-mark-<color>-<height>.webp
   - Color: black on light buttons, white on dark or colored (primary) buttons; where the site has light and dark themes, switch with them.
   - Size: the mark is 4:3. Pick its size by the label's, src the 1x image, and srcset the 2x and 3x for sharp screens:
     · Label 13–14px (small buttons, buttons in a table row): shown 16×12, heights 12 / 24 / 36
     · Label 15–16px (ordinary buttons): shown 24×18, heights 18 / 36 / 54
     · Label 18px or more (large buttons): shown 32×24, heights 24 / 48 / 72
     For example: <img src="https://baocode.dev/brand/baocode-mark-black-12.webp" srcset="https://baocode.dev/brand/baocode-mark-black-24.webp 2x, https://baocode.dev/brand/baocode-mark-black-36.webp 3x" width="16" height="12" alt="">
   - About 6px between the mark and the label, centered vertically. Give width and height, so nothing moves as it loads; leave alt empty, the label says it.
   - Where a square app icon fits (on an import guide, a card): https://baocode.dev/brand/baocode-icon-<size>.png, sizes 16, 24, 32, 48, 64, 96, 128, 256, 512. src the size shown, srcset the one twice that, for example: <img src="https://baocode.dev/brand/baocode-icon-32.png" srcset="https://baocode.dev/brand/baocode-icon-64.png 2x" width="32" height="32" alt="">
   - Where the site sets a CSP, add https://baocode.dev to its img-src.
   Besides these images, don't load any script or style from baocode.dev, and don't call baocode.dev from the backend.

4. When done, tell me which files changed and how to check it: the button should open baocode.dev/import, showing the site's name, the protocol, the URL and the key masked; with BaoCode installed, it then asks to import.

Or pick a button’s style: “Use this style” copies the prompt with that button in it.

What you get

A card in BaoCode’s Settings → Models, among the upstreams that added the import, in a random order each time the page opens. A click on it opens your site, with your promotion parameters if you like. Nobody pays to be listed, and a listing is not an endorsement.

new-api: one line, no code

In System Settings → Chat Settings, add this entry. new-api fills in {address} and {key}, and every key in the token list gets a BaoCode option:

{ "BaoCode": "https://baocode.dev/import#v=1&name=YourSite&protocol=anthropic&url={address}&key={key}" }

Use protocol=openai-chat or openai-responses instead if that is what your users should speak to. Try it once with a key of your own: some versions of new-api give the key without its sk-; write key=sk-{key} then.

Any other site: a link

Next to each key, a link that opens, in a new tab:

https://baocode.dev/import#v=1&name=…&protocol=…&url=…&key=…
ParameterWhat it is
urlrequiredYour base URL, http or https. Without /v1 for Anthropic.
protocoloptionalanthropic (the default), openai-chat or openai-responses.
nameoptionalYour site’s name, as BaoCode lists the upstream.
keyoptionalThe user’s key, whole.
voptional1.

Encode each value with encodeURIComponent. Put them after the #, never after a ?: browsers never send what follows a # to a server, so the key goes from your page to the user’s BaoCode and nowhere else. baocode.dev’s page reads it, takes it off the address bar and opens BaoCode, which shows the user what it is about to add and asks first.

Please don’t load any script from baocode.dev on your key page; a plain link is all it takes. The icons below are fine to load.

Get listed

Once the import works, open an issue with your site’s name, the link for your card, your API’s hosts and a line about it. A maintainer tries the import, asks you for your logo, and adds your card in the next release.

A site is taken off when its import stops working, or when it misleads users.
